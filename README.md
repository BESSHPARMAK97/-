# Дерево строительства

**Сайт:** https://besshparmak97.github.io/stroy-roadmap/

Веб-приложение — дорожная карта строительства объекта в виде **дерева технологий**, как в стратегических видеоиграх. Каждый узел — этап (от концепции до регистрации собственности), внутри этапа — подпункты-чек-лист. Этап «открывается», когда завершены все этапы, от которых он зависит.

Содержание ориентировано на порядок строительства в **Республике Казахстан**: АПЗ и техусловия, комплексная вневедомственная экспертиза, уведомление ГАСК о начале СМР, egov.kz / elicense.kz, НАО «Правительство для граждан», Правовой кадастр.

> Процедуры и нормы меняются — перед применением сверяйтесь с действующим законодательством РК.

## Возможности

- **Шаблоны объектов** — у каждого своя карта этапов:
  - 🏢 Многоэтажный жилой дом — полный путь, плюс долевое участие (21 этап)
  - 🏡 Частный дом (ИЖС) — короткий путь без комплексной экспертизы и тендера (17 этапов)
  - 🏭 Коммерческий / промышленный объект — полный путь, плюс экология и промбезопасность (21 этап)
- **Несколько объектов** — у каждого свой прогресс; переключение, переименование, удаление
- **Приложение на телефон (PWA)** — можно установить на главный экран, работает без интернета
- Два языка: русский и казахский (переключатель «Рус / Қаз»; выбор запоминается)
- Состояния этапов: закрыт / доступен / в работе / завершён; связи между этапами подсвечиваются
- Панель этапа: описание, ответственный, результат, что требуется и что открывается, чек-лист с подсказками
- Свои подпункты в любом этапе
- Уведомления о завершении этапа и открытых новых этапах
- «Свободный режим» — можно отмечать пункты закрытых этапов (работы в реальности часто идут параллельно)
- Масштаб (кнопки или Ctrl + колесо), перетаскивание карты мышью
- Прогресс сохраняется в браузере; экспорт/импорт всех объектов в JSON (файлы старой версии тоже открываются)

## Запуск

Сборка не нужна. Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

Для публикации подойдёт GitHub Pages (Settings → Pages → ветка и корень репозитория).

## Структура

```
index.html            разметка
css/style.css         стили
js/data.js            библиотека этапов и шаблоны объектов — редактируйте здесь
js/i18n.js            переводы интерфейса и казахский текст этапов и шаблонов
js/app.js             логика дерева, объектов, панели и сохранения
sw.js                 офлайн-режим (service worker)
manifest.webmanifest  описание приложения для установки
icons/                иконки приложения
```

### Как добавить этап

1. Добавьте этап в `stages` в `js/data.js`:

```js
{
  id: 'fire', icon: '🧯',
  title: 'Пожарная безопасность',
  who: 'Заказчик', result: 'Согласованные мероприятия',
  desc: 'Краткое описание этапа.',
  items: [
    'Простой подпункт',
    ['Подпункт с подсказкой', 'Текст подсказки']
  ]
}
```

2. Поставьте его на карту нужных шаблонов — строка в `layout`:
   `['fire', 6, 1, ['design']]` — id, колонка, строка, от каких этапов зависит.
3. Добавьте казахский перевод в `js/i18n.js` → `kk.stages` с тем же `id`; подпункты — в том же порядке. Если перевода нет, показывается русский текст.

Чтобы изменить текст или подпункты этапа только в одном шаблоне, используйте `overrides` шаблона (пример — шаблон ИЖС), а перевод — в `kk.templates.<шаблон>.overrides`.

### Обновление офлайн-версии

После изменений увеличьте версию `CACHE` в `sw.js` (например, `stroy-roadmap-v4`). Установленное приложение подхватит новую версию со второго открытия.
