# Дерево строительства

**Сайт:** https://besshparmak97.github.io/-/

Веб-приложение — дорожная карта строительства объекта в виде **дерева технологий**, как в стратегических видеоиграх. Каждый узел — этап (от концепции до регистрации собственности), внутри этапа — подпункты-чек-лист. Этап «открывается», когда завершены все этапы, от которых он зависит.

Содержание ориентировано на порядок строительства в **Республике Казахстан**: АПЗ и техусловия, комплексная вневедомственная экспертиза, уведомление ГАСК о начале СМР, egov.kz / elicense.kz, НАО «Правительство для граждан», Правовой кадастр.

> Процедуры и нормы меняются — перед применением сверяйтесь с действующим законодательством РК.

## Возможности

- Два языка: русский и казахский (переключатель «Рус / Қаз»; выбор запоминается)
- 20 этапов в 6 «эпохах»: Инициация → Исходные данные → Проектирование → Подготовка к СМР → Строительство → Ввод в эксплуатацию
- Состояния этапов: закрыт / доступен / в работе / завершён; связи между этапами подсвечиваются
- Панель этапа: описание, ответственный, результат, что требуется и что открывается, чек-лист с подсказками
- Свои подпункты в любом этапе
- Уведомления о завершении этапа и открытых новых этапах
- «Свободный режим» — можно отмечать пункты закрытых этапов (работы в реальности часто идут параллельно)
- Масштаб (кнопки или Ctrl + колесо), перетаскивание карты мышью
- Прогресс сохраняется в браузере; экспорт/импорт в JSON
- Адаптивная вёрстка для телефона

## Запуск

Сборка не нужна. Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

Для публикации подойдёт GitHub Pages (Settings → Pages → ветка и корень репозитория).

## Структура

```
index.html      разметка
css/style.css   стили
js/data.js      этапы, подпункты и связи — редактируйте здесь
js/i18n.js      переводы интерфейса и казахский текст этапов
js/app.js       логика дерева, панели и сохранения
```

### Как добавить этап

Добавьте объект в `stages` в `js/data.js`:

```js
{
  id: 'fire', col: 6, row: 1, icon: '🧯',
  title: 'Пожарная безопасность',
  who: 'Заказчик', result: 'Согласованные мероприятия',
  desc: 'Краткое описание этапа.',
  requires: ['design'],          // от каких этапов зависит
  items: [
    'Простой подпункт',
    ['Подпункт с подсказкой', 'Текст подсказки']
  ]
}
```

Казахский перевод этапа добавьте в `js/i18n.js` → `kk.stages` с тем же `id`; подпункты — в том же порядке. Если перевода нет, показывается русский текст.

`col` / `row` — колонка и строка на карте; `phases` задаёт, какие колонки входят в каждую эпоху.
